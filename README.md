# Power Automate Desktop Practice Portfolio

Practice project guides by Chereddy Balaji for learning rule-based desktop automation and Excel processing.

## Projects
- [Student Eligibility Screening](rpa-projects/student-eligibility/README.md): evaluate age and marks, validate inputs, and write decisions.
- [Excel Data Entry and Worksheet Processing](rpa-projects/excel-data-processing/README.md): validate records and append valid entries to an Excel worksheet.

## Business automation references
- [Invoice Validation and Summary](rpa-projects/invoice-validation/README.md)
- [Expense Approval Screening](rpa-projects/expense-approval/README.md)
- [Inventory Reorder Report](rpa-projects/inventory-reorder/README.md)

These three projects include runnable Python references (standard library only), sample CSV inputs, expected outputs, and PAD build guides. The Python references were checked against all supplied expected results and reject non-finite numeric values. PAD flows have not been implemented or tested here.

## Status
This repository contains implementation guides, synthetic sample data, expected results, and manual acceptance checks. It does not yet contain exported Power Automate Desktop flows or execution evidence. The expected results are reference outputs, not outputs from a tested PAD flow.

## Tools
Microsoft Power Automate Desktop and Microsoft Excel on Windows.

## Getting started
1. Open a project guide.
2. Import its sample CSV into Excel and save as an .xlsx workbook.
3. Build the described flow and run the acceptance checks.
4. Add your flow export or copied flow actions and screenshots after testing.

All sample records are fictional. Do not commit personal information, credentials, or real student/customer records.
